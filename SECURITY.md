# Security policy

Report security issues privately through [GitHub private vulnerability reporting](https://github.com/juleshall4/atlas/security/advisories/new). Include the affected Atlas version, device and Android version, reproduction steps, and the expected security impact.

Do not open a public issue for a vulnerability before coordinated disclosure. Supported Atlas releases receive security fixes through their normal release channel on [GitHub releases](https://github.com/juleshall4/atlas/releases).
