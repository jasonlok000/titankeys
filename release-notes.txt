# 1.3.1

## App
- Change the keyboard: Push and hold Sym to select a different keyboard.
- Lowercase start: Push Shift at the start of a sentence to type a lowercase letter.

## Critical fix
- Long swipes: This version fixes a critical problem from the two-finger change in 1.3.0. Atlas identified one finger as two fingers and stopped some long swipes, such as "investigating". We are sorry for this problem.
